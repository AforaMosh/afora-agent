# Vercel AI Gateway Afora provider

Official Afora provider plugin for Vercel AI Gateway.

## Install

```sh
afora plugins install @afora/vercel-ai-gateway-provider
```

## Docs

See `docs/providers/vercel-ai-gateway.md` in the Afora repository, or the published docs at `https://docs.afora.ai/providers/vercel-ai-gateway`.
