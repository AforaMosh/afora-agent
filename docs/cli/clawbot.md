# `afora clawbot`

Legacy alias namespace kept for backward compatibility. It registers the same QR command as the top-level CLI, so `afora clawbot qr` accepts every [`afora qr`](/cli/qr) flag.

## Migration

Prefer the modern top-level command:

- `afora clawbot qr` -> `afora qr`
